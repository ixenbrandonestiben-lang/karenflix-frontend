# KarenFlix Frontend

## Estructura del proyecto

```text
karenflix-frontend/
├── index.html               # Página de inicio y punto de entrada
├── pages/                   # Resto de las vistas HTML
│   ├── admin.html
│   ├── detail.html
│   ├── login.html
│   ├── movies.html
│   ├── mylist.html
│   └── register.html
├── assets/
│   ├── css/
│   │   ├── pages/           # Estilos específicos por vista
│   │   ├── components.css
│   │   ├── global.css
│   │   └── variables.css
│   └── js/
│       ├── api/             # Comunicación con el backend
│       ├── components/      # Componentes reutilizables
│       ├── pages/           # Lógica de cada vista
│       └── utils/           # Funciones auxiliares
├── public/                  # Archivos estáticos públicos
│   └── favicon.ico
└── README.md
```
